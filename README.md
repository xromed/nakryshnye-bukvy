# Накрышные буквы — Ташкент

Карта крышных рекламных конструкций (буквы) по паспортам рекламных мест.

- Карта: https://xromed.github.io/nakryshnye-bukvy/
- Слой на uMap: https://umap.openstreetmap.fr/ru/map/map_1466472
- `nakryshnye_bukvy.geojson` — точки с атрибутами, `nakryshnye_bukvy_coords.csv` — таблица координат, `photos/` — фото/эскизы из паспортов.
